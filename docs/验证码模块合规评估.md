# 验证码处理模块 — 合规性评估报告

**评估日期**: 2026-08-11
**评估对象**: 小说爬虫程序的验证码处理功能（自动识别 / 规避策略 / 人工辅助）
**评估范围**: robots.txt 许可、服务条款约定、适用法律风险

---

## 一、robots.txt 实际检查结果（已实地请求验证）

| 站点 | robots.txt | 结论 |
|------|-----------|------|
| tanmixs.com (含 m. 移动端) | `User-agent: *` → `Allow: /`，仅 Disallow `/modules/*` `/google/*` `/click/*` `/ad/*` | ✅ **正文路径明确允许** |
| 3gxs.com | 404（无 robots.txt） | ⚠️ 无明确授权，视为默认允许（按惯例） |
| baoshuism.com | 404（无 robots.txt） | ⚠️ 同上 |
| woqudu.net | 仅对 AhrefsBot/DotBot 等特定 SEO 机器人 Disallow | ⚠️ 通用爬虫未受限 |
| zhiruo.org | 返回 JS 反爬校验页，无法读取 | ⚠️ 无法评估 |

**结论**：robots.txt 层面**不禁止**小说正文页面的抓取；tanmixs 甚至明确允许。

## 二、服务条款（ToS）评估

- 绝大多数中文小说站点（含上述站点）的服务条款**禁止或未授权**自动化程序/爬虫抓取，即使 robots.txt 允许。
- 部分站点 ToS 未明确条款或无法正常访问，无法逐一确认。
- **结论**：ToS 层面存在"未授权自动化访问"的条款风险，且无法通过 robots.txt 的允许来豁免。

## 三、适用法律风险评估（中国法域）

### 3.1 风险分级

| 行为 | 风险等级 | 说明 |
|------|---------|------|
| **自动识别/绕过 WAF 验证码**（ddddocr 字符识别、滑块轨迹模拟、接入打码平台） | 🔴 **高** | 属于"绕过技术保护措施"。司法实践已有明确判例：知乎诉"爬虫"不正当竞争案（破解反爬措施被认定不正当竞争）；"打码平台第一案"（运营打码平台者被追究刑事责任）。即使个人非经营场景起诉概率低，但行为定性明确违法，且打码平台使用会牵连第三方违法活动。 |
| 自动抓取受版权保护的小说全文 | 🟡 中 | 著作权侵权风险（盗版内容源）；个人阅读非传播场景实务追诉率低，但内容本身侵权。 |
| 高频请求/绕过限流对站点造成负担 | 🟡 中 | 《网络安全法》第27条禁止"非法侵入"和干扰网络服务；极端情况可涉及《刑法》破坏计算机信息系统罪（需造成系统实质性损害）。 |
| 请求频率控制、UA 伪装、Cookie 维持（**不绕过**任何技术措施） | 🟢 低 | 属于访问控制范畴，与正常浏览器行为无异；不触及技术保护措施。 |
| 人工辅助验证码（浏览器中由人类用户手动输入） | 🟢 低 | 等价于人类正常访问网站，不涉及自动化绕过。 |

### 3.2 关键红线

> **红线：任何自动化"识别/破解/绕过"网站验证码的技术实现（本地识别、滑块模拟、打码平台 API），以及为此目的接入第三方打码服务。**

依据：
1. 《反不正当竞争法》第 12 条（"互联网专条"）——破解/绕过反爬措施构成不正当竞争；
2. 最高法指导性判例及"爬虫第一案"裁判规则——绕过反爬获取数据的行为定性违法；
3. 打码平台刑事判例——验证码破解产业全链条被认定为犯罪活动；
4. 上述站点验证码（WAF 限流验证码）属于明确的技术保护措施。

## 四、评估结论与实现范围

**结论**：按本项目要求的前置校验标准（"若存在明确禁止或法律风险，则终止开发并给出替代方案"），**终止自动识别/绕过验证码的任何实现**。本模块仅实现合规范围内的功能：

| 实现 | 合规等级 | 说明 |
|------|---------|------|
| ✅ 规避优先策略（频率控制、UA 轮换、Cookie 维持、节流） | 🟢 | 不绕过任何技术措施，仅降低触发概率 |
| ✅ 人工辅助验证码流程（弹浏览器由人类输入） | 🟢 | 等价于人类正常访问 |
| ✅ 监控与容错（触发率统计、重试上限、异常告警） | 🟢 | 纯内部逻辑 |
| ✅ 可插拔架构（策略接口；自动识别策略仅留占位且禁用） | 🟢 | 架构设计本身合规 |
| ❌ ddddocr 本地识别 / 滑块模拟 / 打码平台 API | 🔴 终止 | 法律风险明确，见 3.1 |

## 五、替代方案建议（面向用户实际需求）

1. **降低验证码触发率**（已实现/本模块强化）：`--delay` 请求间隔、`--threads` 并发控制、持久化 Cookie/浏览器会话（tanmixs profile 复用）、UA 伪装；
2. **人工验证码流程**（已实现）：tanmixs 遇到验证码时弹出可见浏览器，由人类用户输入一次，之后复用会话；
3. **验证码触发率异常提示**：监控模块检测到触发率异常时建议降速/暂停；
4. **内容源优选**：优先使用 requests 可直连且无 WAF 的站点（3gxs、baoshuism、woqudu 等），tanmixs 仅用于必要场景；
5. **如需长期自动化**：建议联系站点方获取授权或使用有正式 API 的内容源，避免法律风险。
