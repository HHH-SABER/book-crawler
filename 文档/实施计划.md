### 待评估提案 · 分发形态：便携性评估与"可安装型"取舍（2026-10-01，用户提问触发）

**现状实测**（2026-10-01）：
- **交付形态**：单文件 EXE（onefile，305 MB，PyInstaller，内含 Python+依赖+Flet 客户端+模型），
  **双击即用、无安装、无注册表** ✅
- **便携性缺口**：状态根在 `%LOCALAPPDATA%\小说爬虫\`（历史/日志/阅读进度）——
  **数据不跟程序走**，换机器/换目录后不随带；`抓取结果/`、`站点配置.json`、`网站清单.txt`、
  `captcha_config.json` 倒是在 EXE 旁（BASE_DIR，v2.4.35 已迁正）
- **启动速度**：onefile 每次启动要解包 ~300 MB 到 %TEMP%，实测 9s 就绪
- **源码模式**：`启动*.bat` 优先用 `.runtime\python314`（便携 Python）+ `.venv site-packages`，
  **不依赖系统 Python** ✅
- **体积构成**：EXE 305 MB + `.runtime` 118 MB + `.venv` 488 MB（仅源码模式需要）

**结论：建议保持"便携单文件"为主形态，不做安装版**。理由：
1. 项目定位是个人工具，便携 = 拷走即用、无残留，是当前用户习惯与交付历史；
2. 安装版（Inno Setup/NSIS）引入注册表、安装目录、卸载器，**破坏便携哲学**，收益只有快捷方式；
3. EXE 已 305 MB，安装包体积不会更小。

**若确需"可安装"体验**：用 Inno Setup **包装现有便携产物**（解压 + 开始菜单快捷方式 + 可选卸载），
约半天工作量，两者并存互不影响 —— 列为可选项，非本期。

### 待实施提案 · inspect_page 硬编码 Host 头修复（K29，2026-10-01 提出待评估）

**问题**：`源码/爬虫.py inspect_page()` 请求头写死 `'Host': url.split('/')[2]`；站点做主机级跳转

重试 3 次耗尽**返回空 soup** → 目录解析 0 章。对照实验：去掉 Host 头，同一 URL 返回
200 / 287,806 字符 / **1,517 个章节链接**。**影响任何做 www / 主机级跳转的站点**（不止 siteah）。
requests 本会按 URL 自动生成正确 Host，手写该行无任何收益。

**改法（一行）**：删除该行 `'Host': url.split('/')[2],`。
