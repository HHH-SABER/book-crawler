# 项目审查报告 — 2026-09-08 (第二轮全面审查)

> 审查方式:按域派发 3 个只读子智能体并行深度审查(核心引擎 / GUI+站点适配 / 辅助+工程化),
> 主会话对全部高危发现逐条抽查源码验证。范围:全部源码 + 脚本 + CI + 测试 + 文档。
> 背景:第一轮审查(2026-09-02)后已修复 11 项;本轮用户连续踩到 2 个回归 bug
> (适配器注册丢失、EXE 打包缺口)后发起,重点排查"重构丢副作用"与"打包静默降级"。

## 总体结论

经过两轮修复,工程化基础(CI 门禁、原子写、防抖、线程边界、路径契约)已经扎实,
本轮**未发现新的硬编码密钥、线程回 UI 漏网路径或数据损坏级新缺陷**。
但审查证实了两类系统性风险仍然存在:

1. **"重构丢副作用"**:适配器注册丢失(ae0207e)不是孤例——同模式还有
   load_adapters 先置位后加载、reload_adapters 空窗、内置站点禁用标志不复位、
   build_exe 版本号先改后构建、ensure_flet_cache 半成品缓存不自愈。
2. **"打包/发布链路的静默降级"**:EXE 内 Playwright 引擎必然失效(回退裸 Selenium)、
   CI 发布的 EXE 永远没有 Rust 加速、flet_desktop/icons.json 类缺口已修但
   验证手段(冒烟启动)尚未固化进 CI。
