## 1. 概述

### 1.1 系统定位

多站点小说爬虫：输入小说目录页 URL，自动识别站点 → 抓取目录与正文 →
反爬对抗（验证码/限频/JS 挑战）→ 解码清洗 → 语义质检 → 导出 txt/EPUB。
提供三种使用形态：**Flet 桌面客户端**（主入口，内嵌远控服务）、**手机浏览器
远控面板**（与桌面共享同一任务队列）、**CLI 批量**（无人值守）。

### 1.2 合规边界（硬约束）

仅供学习研究；**验证码自动识别（ddddocr）分发默认必须关闭**——所有涉及
自动识别的代码路径必须在未开启时显式拒绝并转人工兜底。用户可在自己机器的
配置中显式开启（该选择不属于配置漂移）。

### 1.3 规模与质量基线

- Python 约 2.2 万行（最大单文件 `爬虫.py` 7314 行）+ Rust PyO3 扩展
- 测试 334 项（unittest 发现式）+ 手写回归 41 项 + 静态检查
  （`check_undefined_refs.py` from-import 名字级校验）+ 静默 except 执法测试
- 发布：`脚本/发布流程.py` 一键门禁→打包→冒烟→提交→推送（自动剥代理）

### 2.2 进程模型（重要：flet 是双进程）

桌面客户端 = **Python 进程**（协议服务端 + 爬虫线程 + 内嵌远控 uvicorn）
+ **flet.exe 客户端子进程**（Flutter 渲染）。推论：

- Python 侧 `os._exit()` 会留下孤儿客户端窗口 → 退出必须走
  `退出流程.py`（destroy 窗口 → 等待 → 强制结束，7 步）
- 内嵌远控随 Python 进程常驻：**客户端开着 = 远控服务在**（8760）

## 4. 核心组件职责

### 4.1 TaskManager（单一数据源）

- 任务字典（`TaskInfo`：状态/进度/日志/指标/来源/检查点标志）+ 守护线程池；
- **线程纪律**：爬虫线程只写数据结构，绝不碰控件；GUI 通过 1s 轮询 +
  子树级 update 渲染；远控 API 直接读同一对象 → **跨端同步由单实例保证**；
- 同域闸门：同站最多 1 任务在抓（stop-aware，排队 [排队] 可见）；
- `来源` 字段区分 本机/手机（远控页过滤展示）。

### 4.2 NovelSpider（引擎上帝类——有意保留）

7314 行承载编排/解析/清洗/断点。**架构决策**：拆分（U20）经评估为"无行为
收益、动最核心文件"，有意不做；新功能以"事件发布 + 适配器插件"外挂方式
接入，不加剧内聚。风险与缓解见 §8。

### 4.3 反爬对抗链（分层防御）

```
响应 → 反爬检测器.识别
  ├ rate_limit → 指数退避(5/10/20/60) → 连续≥2 次写域冷却(als1010=900s)
  ├ waf_captcha(__wafcaptcha, 401/403/429) ─┐
  ├ waf_verify_page(200 内容型验证页)      ─┤→ WAF 分支:
  │    solve_waf_captcha (ddddocr×5, 需显式开启)     │
  │    → 失败 → solve_waf_captcha_manual             │
  │      (可见浏览器人工输入 → cookie 回灌, 每任务 1 次) ─→ 重取验证
  ├ waf_js_challenge → 浏览器渲染取令牌
  ├ js_cookie → 提取 cookie 重试
  └ ua_block → UA 轮换
所有命中: 风控事件(JSONL) + 速度自适应.note_risk 即时降档
```

### 4.4 内嵌远控（三形态统一）

GUI 启动 → `注入任务管理器(GUI 实例)` + `后台启动()`（守护线程 uvicorn）。
顶栏/远控页开关：`设置启用`（写盘）+ `停止后台`（should_exit 优雅停机）/
`后台启动`（端口占用即报）。状态根、token、推送渠道全部落
`数据/远控配置.json`（gitignore，勿外传）。

## 5. 关键调用与数据流

### 5.1 抓取主流程（单任务）

```
create_task(url) ─► 守护线程 _run_task
   ├ 同域闸门 acquire (排队[排队] / stop 打断)
   ├ run_crawl:
   │   域冷却检查(风控事件) → 章节目录(适配器/通用) → 排序
   │   └ 每章: 反爬识别循环 ─► 提取(适配器→通用→自愈) ─► 解码清洗
   │        └ 质检评分 ─► 通过? 写盘 : 重试→空占位(可续传)
   │        └ 任务事件.发布(进度/引擎/反爬/质检) → TaskManager
   ├ 收尾: 质检汇总报告 + 站点历史 + 风控 task_result + flush
   └ 闸门 release
```

### 5.2 WAF 拦截对抗流（als1010 实测案例）

```
GET 章节 ─► 200 + "访问验证"页(1475B)
  ├ 反爬检测器: waf_verify_page(0.9) → 风控事件 + 降档
  └ WAF 分支: is_waf_captcha_page(200)=True
      ├ ddddocr 开启: 重取页→取 verify 图→识别→POST check_code
      │   (隐藏域+code 沿用页面) → 重取目标验证 → 放行(实测首轮通过)
      └ 未开启/失败: solve_waf_captcha_manual 可见浏览器人工输入
          (每任务 1 次) → cookie 回灌 session → 重取
```

### 5.3 GUI 数据流

```
爬虫线程 ─print─► TaskLogRedirector ─► task.logs / 结构化事件(优先)
GUI 刷新循环(1s, 主线程) ─► 读 TaskManager ─► 子树级 update
内嵌远控(SSE/REST) ─► 同一 TaskManager ─► 手机面板
（正则兜底已停用: TaskLogRedirector.启用正则兜底 = True 一行回退）
```

### 5.4 退出流（7 步，见 退出流程.py）

停远控 → 停托盘 → 运行中任务置 stop_flag 等检查点(≤3s) → 收尾钩子
（显式 flush，os._exit 不跑 atexit）→ destroy 窗口 → 等 1.5s → 强制结束。

## 6. 技术选型说明

| 选型 | 理由 | 已知代价 |
|---|---|---|
| Flet 0.86（桌面） | 纯 Python UI、未来安卓 APK 可能；双进程模型已摸透（退出流程成熟） | 版本迭代破坏性大（钉 0.86）；自动化测试弱（靠黑盒 E2E+人工双验） |
| FastAPI+uvicorn（远控） | token 鉴权/SSE/Pydantic 生态成熟；Python 3.14 已实测 | 多一个框架依赖；静态资源需手动收集 |
| requests→cloudscraper→curl_cffi 降级链 | 按"拦截强度"逐级升压，常规站零开销 | 强 TLS 指纹站在低配环境（Termux）降级 |
| ddddocr（合规开关） | 本地离线 OCR，无第三方打码平台依赖 | 默认关（合规边界），需用户显式开启 |
| Rust PyO3（质检/解码） | CPU 热点 10×+ 加速，GIL 释放真并行 | 双实现同步成本（权重改动须跑 qa_parity） |
| 无数据库（JSON/JSONL） | 零部署、可人工审阅、原子写+防抖已成熟 | 三处书目冗余（见 §8-R2）；超大历史性能待观察 |
| contextvars 事件通道 | 随 copy_context 传播到 worker；无订阅零成本 | 需理解 context 语义（有 H1 修复史与回归测试） |

| 数据/客户端配置.json | gui_app.py | 关闭行为（询问/托盘/退出） |
| 数据/选择器建议.json | 选择器自愈.py | 自愈建议待审 |
| 数据/网站清单.txt | 网站清单.py | 网址+站名+书名清单 |
| 日志/*.log | 日志.py | 按天+5MB 轮转，30 天清理 |

### 9.2 路径契约

- `RESOURCE_DIR`：打包只读资源（_MEIPASS / 源码/）
- `BASE_DIR`：EXE 旁（抓取结果/、站点适配/、站点配置.json、captcha_config.json）
- `STATE_ROOT`：`%LOCALAPPDATA%\小说爬虫\`（使用痕迹，首次运行自动迁移旧数据）

### 9.3 文档导出方式（本说明书）

- **源格式**：Markdown（`文档/程序架构分析说明书.md`）——版本可追踪、
  AI/人工均易编辑、ASCII 图表全平台可读，故以此为准；

  或先导 docx 再用 Word 另存 PDF（图表保真最稳）。
