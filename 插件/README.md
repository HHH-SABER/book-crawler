# 浏览器插件 · 凭据中继（P1）

把你在浏览器里的**真实登录 Cookie**（含 HttpOnly、JS 算出的反爬 Cookie）推给本机
小说爬虫，爬虫的三个 HTTP 引擎立刻带上它去抓 —— 解决"JS 挑战型 WAF / 登录态拿不到"
这类纯爬虫过不去的坎。

> 只对**你明确加入白名单**的站点生效。爬虫必须在本机运行（127.0.0.1）。

## 安装（Chrome / Edge，开发者模式加载）

1. Chrome 打开 `chrome://extensions`（Edge 是 `edge://extensions`）
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」→ 选中本目录（`插件/`）
4. 插件栏出现「小说爬虫 · 凭据中继」

## 配置

1. 打开小说爬虫程序 → 左侧「远控」页 → 复制 **token**（端口默认 8760）
2. 点插件图标 → 在「端口 / token」填入 → 点「保存设置并测试连通」
3. 看到 `✅ 已连接小说爬虫` 即成功

## 日常使用（两种方式）

- **对单个站点**：打开目标小说站（确保已正常访问、能看到正文）→ 点插件图标 →
  「加入白名单并推送」→ 爬虫对应该域的请求自动带上这些 Cookie
- **自动同步**：加入白名单的域每 5 分钟自动重新推送一次（浏览器里的 Cookie 变了
  会自动跟上）

## 边界与安全

| 项 | 说明 |
|---|---|
| 白名单 | Cookie 只接受白名单内的域；白名单存在爬虫侧（`数据/插件白名单.json`），删除条目即撤销 |
| 仅本机 | 爬虫侧只接受 127.0.0.1 的推送，手机/局域网不可用 |
| 不做别的 | 插件不解析、不存书、不改爬虫状态——只搬 Cookie |
| 权限 | 读取任意站点 Cookie 需要 `<all_urls>` 主机权限（开发者模式自用插件，可审查本目录全部源码） |
| 不可用场景 | 爬虫没开 / token 未填 / 站点被 IP 层封锁（此时浏览器同样访问不了） |

## 排障

- `连不上`：程序没开、端口不对、token 不对；确认「远控」页显示服务已启动
- `不在白名单`：先点「加入白名单并推送」
- `没有可推送的 Cookie`：该站还没正常访问过（先打开一次首页/登录）
