📐 界面布局说明

🗂整体布局结构

采用 Windows 桌面应用常用的三段式布局（顶部标题栏 + 左侧导航 + 主内容区），从上到下、从左到右层次分明：

① 标题栏 (52px)
② 侧边导航 (220px)
③ 主内容区 (自适应)

各区域功能

  • 标题栏：左侧应用图标与标题，右侧主题切换按钮（醒目位置，一键切换日/夜模式）与标准窗口控制（最小化 / 最大化 / 关闭）
  • 侧边导航：4 个主功能入口（抓取工作台、爬取历史、站点管理、运行日志），底部状态栏显示实时运行状态
  • 主内容区：承载各页面核心功能，内边距 20px，页面间距 20px，呼吸感充足

🔗层级关系与交互逻辑

页面层级（从高到低）

  • L0 全局层：标题栏 + 侧边导航 + 状态栏，始终可见，跨页面共享
  • L1 页面层：4 个主页面通过导航切换，使用 Stack 模式保活状态
  • L2 卡片层：功能模块以卡片为单位组织，卡片内包含标题栏 + 内容区
  • L3 抽屉/浮层层：右侧详情抽屉、对话框、提示条，上下文相关
  • L4 行内展开层：表格行内展开详情，不打断浏览流

核心交互流

  • 抓取流程：输入URL → 选择模式 → 点击开始 → 任务出现在表格 → 实时进度/日志更新 → 完成后状态变更
  • 任务联动：点击行选中 → 日志条自动切换到该任务日志 → 右侧抽屉同步显示详情
  • 页面切换：点击侧边导航切换页面，抓取任务在后台持续运行

⬇️抓取工作台 · 功能划分

输入控制区

  • URL 输入框：自适应拉伸，支持回车快速开始，粘贴即校验
  • 模式选择：完整抓取 / 仅看目录 / 测试首章 / 章节区间，区间模式显示起止章输入
  • 主操作按钮：开始（蓝色主按钮）+ 停止（红色危险按钮），状态联动禁用
  • 次操作行：导入网址、粘贴网址、断点续传开关、输出目录、打开文件夹

任务表格区

  • 8 列布局：任务/URL → 进度 → 状态 → 引擎 → 反爬 → 耗时 → 质检 → 操作
  • 进度列：迷你环形进度条 + 数值，一目了然
  • 状态列：胶囊标签，颜色区分进行中/完成/失败/等待
  • 操作列：展开详情、预览文件、重下、删除，4 个图标按钮紧凑排列

日志条

  • 默认 130px 高度紧凑显示，点击手柄可放大至全屏高度
  • 终端深底 + 等宽字体，按级别着色（信息/成功/警告/错误/调试）
  • 自动滚动到最新行，跟随选中任务切换

右侧详情抽屉

  • 大进度环：64px 环形进度 + 百分比数值 + 状态标签
  • 2×2 指标网格：引擎、反爬、质检、增量跳过 4 项核心指标
  • 降级链展示：显示引擎自动降级路径
  • 输出文件：文件名、大小、章节数，一键打开所在文件夹

📑其他页面 · 功能划分

爬取历史页

  • 5 张统计卡：总请求数、新增、更新、未变化、失败，顶部横向排列
  • 过滤器栏：站点下拉、时间范围下拉、结果类型 chips（全部/新增/更新/未变化/失败）
  • 双视图切换：URL 明细 / 站点汇总，分段控件切换
  • 明细表：7 列数据，站点行可点击跳转到该站点筛选

站点管理页

  • 风控告警横幅：24 小时高风险站点 + 站点漂移告警，红色醒目
  • 工具栏：新增站点、全部测试、导入、导出
  • 适配器插件区：橙色主题卡片，展示外部插件列表与能力标签
  • 站点表格：域名 + 模式 + 状态（健康度/反爬/探测） + 启用开关 + 操作
  • 健康度分级：≥80% 绿色、≥50% 橙色、<50% 红色

运行日志页

  • 日志工具栏：来源过滤、级别过滤、关键词搜索、复制/导出/清空
  • 终端风格日志：深色背景 + 等宽字体，时间戳 + 来源 + 内容
  • 级别着色：INFO 原色、SUCCESS 绿色、WARNING 黄色、ERROR 红色、DEBUG 灰色

🎨日间/夜间模式切换设计

切换按钮位置

主题切换按钮置于标题栏最右侧，始终可见、一键可达：

  • 使用胶囊形按钮，含图标 + 文字标签，视觉重量适中
  • 悬停时轻微上浮 + 阴影，提供明确的可点击反馈
  • 图标随主题变化：日间模式显示月亮🌙（切换到夜间），夜间模式显示太阳☀️（切换到日间）
  • 文字标签同步更新："夜间" / "日间"

切换过渡效果

  • 所有颜色属性 250ms ease-out 平滑过渡，无闪烁感
  • 图标 180° 旋转动画，增加切换仪式感
  • CSS 变量驱动，所有组件自动适配，无需单独处理

可读性保障

  • 正文文字对比度 ≥ 7:1（AAA 级）
  • 次级文字对比度 ≥ 4.5:1（AA 级）
  • 强调色在对应底色上对比度 ≥ 3:1
  • 状态色不仅靠颜色区分，同时配有文字标签和图标
